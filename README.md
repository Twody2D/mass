# Mass

Экспериментальная 3D-симуляция на Godot 4: до **10 000** простых персонажей одновременно живут
на процедурно генерируемом острове. Проект делается в первую очередь для записи YouTube-видео —
масштаб и стабильность важнее графики.

> ⚠️ **Статус: скелет проекта.** Симуляция, остров, толпа и HUD ещё не реализованы —
> см. [TODO.md](TODO.md).

## Требования

- **Godot 4.7 или новее**, вариант **Standard** (не .NET) — [скачать](https://godotengine.org/download)
- Рендерер **Forward+** (задан в `project.godot`, менять не нужно)

Устанавливать ничего не требуется: Godot — один исполняемый файл.

## Как открыть проект

1. Запусти Godot.
2. **Import** → укажи файл `project.godot` в корне репозитория → **Import & Edit**.
3. Первый импорт занимает несколько секунд (генерируется папка `.godot/`, она в `.gitignore`).

## Как запустить

- **F5** — запустить главную сцену (`scenes/main.tscn`).
- **F8** — остановить.

VSync в проекте **отключён намеренно**: FPS должен быть измеримым, а не упираться в частоту
монитора.

## Как изменить количество ботов

Одно значение в [scripts/core/game_config.gd](scripts/core/game_config.gd):

```gdscript
const DEFAULT_BOT_COUNT := 10000
```

Целевые режимы: `100` — debug, `1000` — development, `5000` — stress test, `10000` — основной target.

Значение restart-scoped: оно читается при построении симуляции, поэтому применяется при запуске
или рестарте, а не мгновенно. Допустимый диапазон — от `1` до `100000`; выход за него
обрезается с предупреждением, а не молча.

## Как изменить seed карты

Там же:

```gdscript
const DEFAULT_MAP_SEED := 20260826
```

Один и тот же seed даёт одну и ту же карту и одинаковый старт симуляции.

## Debug mode

🚧 *Будет доступно после реализации HUD.*

Экранный оверлей с FPS, количеством ботов, живыми, номером тика и временем симуляции, плюс
управление: pause / resume / restart, скорость симуляции, задание `BOT_COUNT` и seed.

## Структура репозитория

```
project.godot          конфигурация проекта Godot
scenes/                сцены (главная — main.tscn)
scripts/
  core/                game_config.gd — все настраиваемые константы (autoload)
  simulation/          данные и логика ботов
  rendering/           рендер толпы
  world/               генерация карты и запросы к ней
  events/              система событий
  camera/              камеры
  ui/                  HUD и debug-панель
assets/                меши и материалы
```
